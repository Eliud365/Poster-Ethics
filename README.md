# 🛡️ Strathmore Cybersecurity Awareness

### **Stay Sharp. Stay Safe. Think Before You Click!**

A simple cybersecurity awareness website created to educate students and everyday technology users about common online risks and safer digital habits.

## 🎯 Purpose

The goal of this project is to make cybersecurity awareness **simple, quick, and accessible**.

The website provides basic tips on:

* 🔑 **Using Strong Passwords**
* 📧 **Spotting Phishing Emails**
* 🔒 **Securing Your Devices**
* 📶 **Using Wi-Fi Safely**

## 💻 Built With

* HTML
* CSS
* JavaScript
* Particles.js

## 🌐 How It Works

The website is designed as a simple awareness resource that can be **shared with different people**. Users can open it, read the safety tips, and learn how to protect themselves from common cybersecurity risks.

No account or personal information is required.

## 🚀 Run the Website

1. Download or clone this repository.
2. Open the project in **VS Code**.
3. Open `index.html`.
4. Click **Go Live**.
5. The website will open in your browser.
